# Java Lab 3 - Singly Linked List

An early implementation of a singly linked list using custom `Node` objects and a reference to the first node (`head`).

## Concepts
- Node links and traversing with `current = current.next`
- Inserting at the front or back
- Inserting before a particular value
- Checking whether the list is empty
- Displaying linked-list contents

## Files and running
`Node.java`, `LInkedlist.java`, and `main.java` use package `person`. Import them into that package in Eclipse and run `main.java`.

## Practice
Test an empty list, a single node, and insertion before an existing or missing value. The insertion-before method checks whether the target value exists.
